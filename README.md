# ofCourse

A phone-first web app that gives college students one calm place for everything due, plus a planner, notes, and typed-in grades. Hoot the owl guides new students in.

**Try it locally:** `npm install`, then `npm run dev`. Run the tests with `npm test`.

## Tech stack
Vite + React + TypeScript, ical.js, and Motion.
